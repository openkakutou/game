# Module: result
**Role:** The round/match result overlay (backlog item 007). `outcome.ts` is pure mapping logic, no DOM/WASM: turns the core snapshot's `roundWinner`/`winner` into a clean "who won" reading — a side wins, or no side (a double KO, a timeout at equal health) is a draw; the bridge has already refused any value outside -1/0/1. `result-screen.ts` builds the overlay once (`createResultOverlay`) and mutates it in place on each show: a round result shows the round winner (or a draw) via a one-shot `aria-live` announcement, plus a separate, non-live countdown that auto-advances after a fixed delay (`onRoundResultDone`) — a round result is not a decision, so no button is asked for; a match result instead shows the overall winner (or a draw) with explicit Rematch/Back to select actions and no countdown. `hide()`/`dispose()` cancel any pending countdown so a stale timer can never fire once the caller has moved on.
**Files:** `src/result/outcome.ts`, `src/result/result-screen.ts`
**Exports:** `OutcomeWinner`, `RoundEndView`, `MatchEndView`, `deriveRoundOutcome(snapshot): RoundEndView | null`, `deriveMatchOutcome(snapshot): MatchEndView | null`, `ResultOverlayOptions`, `ResultOverlay`, `DEFAULT_ROUND_RESULT_DELAY_MS`, `createResultOverlay(options): ResultOverlay`
**Depends on:** `modules/i18n.md` (`t`, `onLocaleChange`)
