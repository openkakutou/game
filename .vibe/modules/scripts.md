# Module: scripts
**Role:** Dev-tooling scripts outside the app bundle. `download-wasm.mjs` downloads a WASM dependency's release build, targeting `character` (default) or `stage`. The `stage` target's `wasm_exec.js` is written to disk under its own name (`stage-wasm_exec.js`) rather than overwriting `character`'s own copy, since the modules are released independently. (The game core is not downloaded: `scripts/build-core-wasm.sh`, run by `npm run wasm:core`, builds it from `native/`.) `prepare-visual-fixtures.mjs` (backlog item 011) copies the already-downloaded `character`/`stage` WASM assets from `public/wasm/` into `tests/visual/fixtures/wasm/`, the dedicated `publicDir` the visual regression suite's own Vite config serves from — clearing any stale copy first and failing fast with a named error if a source asset is missing.
**Files:** `scripts/download-wasm.mjs`, `scripts/prepare-visual-fixtures.mjs`
**Exports:** `downloadWasmRelease(options): Promise<string[]>`, `main(argv, overrides): Promise<number>`, `DownloadError`, `EXIT_CODES` (from `download-wasm.mjs`); `prepareVisualFixtures(options): Promise<string[]>`, `main(overrides): Promise<number>`, `PrepareVisualFixturesError`, `EXIT_CODES` (from `prepare-visual-fixtures.mjs`)
**Depends on:** (none)
