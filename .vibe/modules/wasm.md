# Module: wasm
**Role:** One bridge per WASM dependency, each its own Go program with its own runtime instance: `bridge.ts` bridges to the `character` WASM module, `stage-bridge.ts` to the `stage` WASM module (both only supply drawing data until backlog item 067 moves it to the core), `core-bridge.ts` to the game core (`native/cmd/core-wasm`, the same Go code the native game plays matches with; `engine.wasm` is no longer loaded). All expose a typed loader/caller returning either the result or a descriptive error, never throwing — including a failed runtime instantiation itself, caught by each bridge's own `ensureGoRuntimeReadyOrError` wrapper (backlog item 008). `bridge.ts`/`stage-bridge.ts` additionally expose batched `resolveSprites()`; `stage-bridge.ts` also `resolveAnimationFrames()` and, on `loadStage()`'s response, a stage's background music path (backlog item 013); `load()` in `bridge.ts` takes an optional 5th `sndBytes` argument decoding a `.snd` file into `CharacterSummary.sounds`. `core-bridge.ts` (types in `core-types.ts`) wraps the global `OpenKakutouCore`: `mountFiles()` adds files to the core's in-memory file system (a name is mounted once per page), `startMatch()`/`tick()`/`nextRound()`/`closeMatch()` each send one JSON string and parse the `{"ok":true,...}` / `{"ok":false,"error":{"reason"}}` reply, and the bridge validates the state snapshot (`MatchSnapshot`: tick, round, timer, `roundEnded`, `outcome`, `over`, `winner`, `roundWinner`, `wins`, `camX`, both fighters' position/facing/animation/health/power, and the tick's sound `cues`) — any invalid field fails the whole reply as an error, so downstream code can trust the types.
**Files:** `src/wasm/bridge.ts`, `src/wasm/types.ts`, `src/wasm/stage-bridge.ts`, `src/wasm/stage-types.ts`, `src/wasm/core-bridge.ts`, `src/wasm/core-types.ts`
**Exports:** `loadCharacter(defBytes, airBytes, sffBytes, cnsBytes, sndBytes?, options?): Promise<CharacterResult>`, `resolveSprites(sffBytes, requests, overrideBytes?, options?): Promise<SpritePixelResult[]>`, `resetWasmBridgeForTests(): void`, `WasmBridgeOptions`, `CharacterSummary` (incl. `sounds: SoundGroup[]`), `CharacterResult`, `Sound`, `SoundGroup`, `loadStage(defBytes, options?): Promise<StageResult>`, `resolveSprites` (stage), `resolveAnimationFrames(requests, options?): Promise<{ok, sprites}|{ok, error}>`, `resetStageWasmBridgeForTests(): void`, `StageWasmBridgeOptions`, `StageSummary` (incl. `musicFile: string`), `StageResult`, `mountFiles(files, options?): Promise<CoreResult<{}>>`, `startMatch(request, options?): Promise<CoreResult<StartMatchData>>`, `tick(id, inputs, options?): Promise<CoreResult<MatchSnapshot>>`, `nextRound(id, options?)`, `closeMatch(id, options?)`, `resetCoreBridgeForTests(): void`, `CoreWasmBridgeOptions`, `CoreFile`, `TickInputs`, and the `core-types.ts` types (`MatchSnapshot`, `StartMatchData`, `StartMatchRequest`, `FighterSnapshot`, `SoundCue`, `TickInput`, `RoundOutcome`, `Facing`, `Side`, `CoreResult`)
**Depends on:** (none — talks directly to the `character`/`stage`/core WASM modules)
